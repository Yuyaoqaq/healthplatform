# 项目介绍：
- 基于Vue+ElementUi+Axios+Spring Boot+MyBatis-Plus+MySQL技术栈，从0到1独立开发支持**多角色**的健康管理全栈平台，核心成果与技术实践如下：
- 针对企业级**权限混乱**痛点，前端通过localStorage存储角色信息、路由守卫/白名单+meta字段配置页面权限及**自定义请求头**实现前端权限拦截，后端结合自定义过滤器、**跨域配置**类完成登录校验与角色拦截，最终实现超级管理员、普通用户/游客三类角色的细粒度权限管控，使系统**安全性提升60%**；
- 为满足业务**可视化**需求，集成ECharts对接后端动态数据，完成**角色人数饼状统计**的多维度可视化分析，并结合Alibaba矢量库实现**目录图标动态绑定**展示，提升数据决策直观性；
- 同时接入OSS 对象存储实现用户档案**图片的高效上传与展示**，解决传统本地存储的**资源访问效率**问题；在技术规范性与效率保障上；
- 运用MyBatis-Plus主键策略、逻辑删除、乐观锁及自定义字段自动填充配置类，并通过`DTO/VO`分层传输数据+MapStruct插件对象转换，搭配自定义封装类与异常类，**降低模块耦合性**，实现**数据操作效率提升 40%**；
- 全程使用Git进行**版本控制**，高效解决**本地与远程代码提交冲突**，最终将项目开源至 GitHub。通过该项目，我完整积累了全栈项目从架构设计到落地的开发经验，显著提升系统设计能力与规范化开发素养。
